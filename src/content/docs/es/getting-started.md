## Instala las dependencias

Instala las versiones que figuran en el archivo de bloqueo.

```sh
pnpm install --frozen-lockfile
```

## Inicia el servidor de desarrollo

Abre la URL que aparece en la terminal.

```sh
pnpm dev
```
