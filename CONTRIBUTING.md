# Contributing

## Open an issue

Search existing issues first and choose the form that matches your report.

- **Bug report** covers build failures, routing problems, and unexpected site behavior. Include reproduction steps, expected and actual behavior, and your local environment.
- **Documentation feedback** covers confusing, missing, or incorrect instructions. Include the page URL or file path and the language.
- **Feature request** describes a use case and what the template should do to support it.

## Open a pull request

Keep each change focused. Describe what changed, link any related issue, and mention how you verified the change. Include screenshots for visible changes and note which locales you checked when updating shared navigation or layout.

```sh
pnpm install --frozen-lockfile
pnpm build
```
